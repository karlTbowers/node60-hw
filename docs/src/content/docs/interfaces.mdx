## Net-level rules

- Name all six outputs and all three SNS nets; document every SPI diagnostic-mux mapping.
- Route LAN8670 INH directly to the first LMQ66430 EN and chain regulator EN pins for rail order. Do not add FS26, a wake latch, or an MCU-controlled gate in this path.
- Keep VDDAU on the nanopower always-on LDO and put LAN8670 VDDA/VDDP, MCU, flash, and all remaining logic on switched rails. Enforce VDDA ≤ VDDAU + 0.5 V through all transients.
- Place IS25LP032D-JNLA3 on switched 3V3_MAIN with dedicated chip select, decoupling, and accessible SPI test pads.
- Label the SW-divider ADC net **BATT_MON** and its reported quantity **VBAT_RAW**; ensure its ADC tap does not add material parked current, and set cold-crank behavior with the separate UVLO pin.
- Place the shared 0.25 mΩ RSENSE between the DGATE and HGATE FET stages. Route separate star Kelvin pairs from the resistor pads to LM74910H and INA228A-Q1, expose both nodes as test points, and couple NTC_RSENSE tightly to the resistor body.
- Route every buck/MCU and output branch from VOUT after the Q2 disconnect FET so shared RSENSE measures the complete downstream current.
- Fit R(ILIM) = 32 kΩ 1%, RSET = 50 Ω, and TMR ≈68 nF; route LM74910H FLT to the MCU as LM_FLT_L and leave IMON floating when INA228 is populated.
- Name and route NTC_RSENSE plus NTC_SW1–NTC_SW3 to separate ADC channels; keep divider returns quiet and document each thermistor’s exact coefficients.
- Place TMP175-Q1 beside the ideal-diode NFET bank, share the INA228 I²C bus with a distinct address, and reserve ALERT routing to the MCU.
- Route TPS3702-Q1 directly from 3V3_MAIN to RESET_L (S32K344 RESET_b); document threshold variant, reset timing, pull-up domain, and interaction with MCU POR/LVD.
- Annotate every 10 A net with copper weight, geometry, via array, connector contact, and 14 AWG minimum harness.
- Keep PHYAD hardware strapping separate from commissioned PLCA node identity.
- Add test points on all rails, INH, T1S_IRQ_L (PHY IRQ_N), MDC/MDIO, reference clock, SPI, and all SNS nets.
- Show reset states for each switch's CS_L, LHI and FLT/WAKE.
- Mark every unverified sequence, package ball, and connector mate as release-blocking.

## Schematic net names

The schematic and this site follow the naming rules adopted on 2026-10-22 (handbook chapter 05): rails keep their Rev A names, active-low signals end in `_L`, buses are `<BUS><n>_<PURPOSE>_<SIGNAL>`, differential pairs end in `_P` / `_N`.

| Device pin | Schematic net(s) |
|---|---|
| S32K344 RESET_b, TPS3702 RESET, PHY RESET_N | `RESET_L` |
| PHY IRQ_N | `T1S_IRQ_L` |
| Output-switch FLT/WAKE (×3) | `SW1_FLT_L`, `SW2_FLT_L`, `SW3_FLT_L` |
| LM74910H FLT | `LM_FLT_L` |
| TMP175 ALERT | `TMP175_ALERT_L` |
| LHI | `SW_LHI` (MCU PTE4, pulled low on each switch) |
| SNS (×3) | `SW1_SNS`, `SW2_SNS`, `SW3_SNS` |
| Switch SPI, one bus per switch (DEC-018) | `SPI4_SWITCH1_*` (U601), `SPI5_SWITCH2_*` (U701), `SPI3_SWITCH3_*` (U801); each `_SCK`, `_MOSI`, `_MISO`, `_CS_L` |
| Flash SPI | `SPI2_FLASH_SCK`, `SPI2_FLASH_MOSI`, `SPI2_FLASH_MISO`, `SPI2_FLASH_CS_L` |
| Shared I²C | `I2C0_TELEMETRY_SCL`, `I2C0_TELEMETRY_SDA` |
| RMII / MDIO | `RMII0_T1S_*`, `MDIO0_T1S_MDC`, `MDIO0_T1S_MDIO` |
| T1S pair | `T1S_P`, `T1S_N` |
| RSENSE± star taps | `VBAT_D`, `VBAT_Q2D` (the shunt is 2-terminal; Kelvin taps start at its pads) |
