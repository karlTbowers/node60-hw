Each output gets a sealed, independently protected path; the aggregate input is treated as a 60 A interconnect problem.

| Interface | Architecture | Release condition |
|---|---|---|
| Six outputs | TE DEUTSCH DT13-2P, one 2-pin right-angle header per output (<Ref id="DEC-013" />); 10 A each; 14 AWG minimum | Pin assignment decided; contact temperature rise at 10 A proven up to +125 °C ambient; DT06-2S, sockets, wedgelock, wire, and panel seal frozen together |
| Battery input | Metri-Pack 480/630 class or dual feed | Prove complete 60 A path; use multiple contacts or feeds |
| Power return | Matched high-current return | No chassis-only return assumption |
| 10BASE-T1S | Separate sealed two-way twisted pair | Vehicle-level protection and termination strategy |
| Complete node cable | Exactly four conductors: T1S twisted pair + battery-direct power + ground | No KL15, ignition, or local hardwire wake input; controller ECU must provide T1S wake (<Ref id="REQ-NET-001" />) |

## Output connectors

Each output has its own **TE DT13-2P** header: DEUTSCH DT series, 2 pins at 5.46 mm, right angle, with a panel flange seal. It mates a DT06-2S plug with a W2S wedgelock and size 16 sockets. TE rates the contact 13 A with 14 or 16 AWG wire, −55 to +125 °C, with no derating curve. TE has not tested the header's ingress protection; it seals against the enclosure wall through TE's panel cutout. HISENG CH-AK-DT13-02 (Alibaba) and Jorch DT13-2P (AliExpress) are alternates on the same footprint, fitted only after a sample check. See <Ref id="DEC-013" long />.

<Aside type="caution" title="Open: output pin assignment">
Either pin 1 = OUTx with pin 2 = local ground return, which brings up to 60 A of load return current back through the node's ground conductor, or OUTx on both pins, which halves the contact current and leaves load returns on vehicle ground. The user decides; DEC-013 lists the trade-offs.
</Aside>

## Fusing

Place the primary fuse at the battery/source end. If the 60 A path is split, fuse each feed and prevent back-powering through an undersized path. Final values coordinate wire ampacity, contact derating, load inrush, PCB fault energy, and the smart-switch curve. Use branch fuses wherever the main fuse cannot protect an output conductor or connector fault.

<Aside type="caution" title="Connector freeze condition">
Connector families are architectural selections, not released mating sets. Freeze exact housings, terminals, seals, wire sizes, and keys together; validate temperature rise with all intended adjacent circuits loaded.
</Aside>
