## Rev A

The first complete architecture. Earlier drafts were incomplete and are not numbered revisions. Rev A replaced these draft choices:

- LM74800QDRRRQ1 and its standalone 0.5 mΩ shunt replaced by LM74910HQRGERQ1 with a shared 0.25 mΩ RSENSE, adding input-rail overcurrent protection ([DEC-001](../decisions/dec-001/)), with INA228A-Q1 as total-current monitor ([DEC-002](../decisions/dec-002/)).
- The FS26 SBC removed in favour of a discrete INH-gated power tree with a nanopower VDDAU LDO ([DEC-004](../decisions/dec-004/)).
- IS25LP032D-JNLA3 diagnostic flash added ([DEC-011](../decisions/dec-011/)), with T1S-only wake and controller-commanded shutdown ([DEC-007](../decisions/dec-007/)).

Rev A was first written as a single-file HTML document (labelled Rev C at the time) and ported to this site on 2026-10-21 (handbook chapter 08). That file is no longer published; it remains in the repository's git history.
