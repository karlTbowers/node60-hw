**Passed on 2026-10-28.** The user signed off the audit of all 257 balls of U401 (S32K344EHT1MMMST, 257MAPBGA), after a machine cross-check that found no differences.

## Method

The schematic netlist (U401 ball, symbol pin name, net) was compared with three NXP sources:

| Source | What it checked |
|---|---|
| S32K3xx Reference Manual IOMUX attachment `S32K344_S32K324_S32K314_IOMUX.xlsx` (Nov 2025 build) | Port or supply name on every ball; for each used signal, that the planned function exists on that ball and which MSCR/IMCR setting selects it |
| S32K3 Hardware Design Package Rev. E2, IBIS model `s32k344_bga257_3v.ibs` | Port name on every signal ball; supply names (each supply listed once) |
| S32K3 Hardware Design Package Rev. E2, BSDL `S32K344_bga257_996001D.bsdl` | Port on every boundary-scan ball |

The library symbol was generated from the IOMUX table, so the IBIS and BSDL files are the independent checks. The NXP tables and select values stay in the private review sheet; this page lists only what the schematic already shows.

## Result

- **Ball map:** 257 of 257 balls match. The 220 signal and oscillator balls match all three sources. The 37 supply balls match the IOMUX supply table, and their names match the IBIS model where it lists them.
- **Functions:** all 43 used signals have their planned function on their ball. External interrupt lines are all different (EIRQ 0, 1, 2, 6, 17, 23).
- **RMII:** TXD0/TXD1 sit on the opposite balls from NXP's TJA1100 example (PTD7/PTC2); each ball offers both data lines, so this is valid. CRS_DV, RX_ER, MDC and MDIO use NXP's other listed balls.
- **Unused:** 177 balls are unconnected, including JTAG_TDI (F8): debug is SWD only. Unused GPIOs stay disabled, as the Hardware Design Guidelines Rev. E2 (Table 33) require.

### Addendum, 2026-10-28 (DEC-017)

Two unused balls became outputs for the termination relay driver: PTD0 (F3) → `T1S_TERM_END` and PTD1 (E3) → `T1S_TERM_DROP`. Both are plain GPIOs in NXP's IOMUX table (GPIO[96], GPIO[97]) and match the IBIS and BSDL port names. The ball map is unchanged.
